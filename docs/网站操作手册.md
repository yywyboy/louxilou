## 四、文章与公告管理

### 4.1 发布文章

1. 打开 https://supabase.com/dashboard
2. 选择项目 → **Table Editor** → **posts**
3. 点击 **Insert row**，填写字段：

| 字段 | 说明 | 必填 |
|------|------|------|
| `title` | 文章标题 | 是 |
| `summary` | 摘要 | 否 |
| `content` | 内容（Markdown） | 是 |
| `cover` | 封面图 URL | 否 |
| `tags` | 标签数组，如 `["技术","Vue"]` | 否 |
| `category` | 分类（见下表） | 否 |
| `author_name` | 作者名 | 否 |

4. 点击 **Save**

**分类对应关系**：

| ID | 显示名 |
|------|------|
| `tech` | 技术 |
| `life` | 生活 |
| `reading` | 读书 |
| `thoughts` | 随想 |

### 4.2 编辑/删除文章

- **编辑**：Table Editor → posts → 点击行 → 修改 → Save
- **删除**：Table Editor → posts → 选中行 → Delete

### 4.3 公告管理

在 Supabase **Table Editor** → **announcements** 中操作：

| 字段 | 值 |
|------|-----|
| `content` | 公告内容（纯文本） |
| `is_active` | `true` 显示 / `false` 隐藏 |

- 首页只显示最新的一条活跃公告
- 公告表有 RLS 策略，需在 Supabase 后台操作

### 4.4 评论管理

```sql
-- 删除某篇文章的所有评论
DELETE FROM comments WHERE post_id = '文章UUID';

-- 删除特定评论
DELETE FROM comments WHERE id = '评论UUID';
```

## 五、图片库管理

### 5.1 添加图片

1. 将图片放入 `public/photos/` 目录
2. 命名格式：`photo (序号).jpg`（如 `photo (1).jpg`）
3. 在 Supabase `photos` 表中添加记录，设置分类标签
4. 重新构建并部署

### 5.2 图片分类标签

| ID | 名称 |
|------|------|
| `landscape` | 风景 |
| `city` | 城市 |
| `people` | 人物 |
| `animal` | 动物 |
| `food` | 美食 |
| `art` | 艺术 |
| `nature` | 自然 |
| `architecture` | 建筑 |

### 5.3 图片压缩

使用 Python Pillow 批量压缩：

```python
from PIL import Image
import os, glob

src = r'L:\public\photos'
for f in glob.glob(os.path.join(src, '*.jpg')):
    img = Image.open(f)
    img.thumbnail((1200, 1200), Image.LANCZOS)
    img.save(f, 'JPEG', quality=75, optimize=True)
```

或使用在线工具 https://tinypng.com

## 六、藏书阁 — 轻小说导入

### 6.1 导入步骤

1. 将 TXT 文件放入 `L:\import\` 目录
2. 运行命令：`npm run import-books`
3. 工具自动完成：分组、生成封面、复制文件、写入 books.ts

### 6.2 文件命名规则

```
书名 卷号.txt
```

示例：
```
刀剑神域 1.txt
刀剑神域 2.txt
刀剑神域 3.txt
```

- 同一书名不同卷号自动归为一部作品
- 不带卷号的文件识别为单卷本
- 已存在的书籍自动跳过

### 6.3 导入后处理

| 任务 | 操作 |
|------|------|
| 替换封面 | 用真实封面替换 `public/books/images/{书名id}/cover.jpg`（推荐 300×400） |
| 修改作者 | 编辑 `src/data/books.ts`，修改 `author` 字段 |
| 修改简介 | 编辑 `src/data/books.ts`，修改 `description` 字段 |

### 6.4 手动添加书籍

编辑 `src/data/books.ts`：

```typescript
{
  id: 'book-id',
  title: '书名',
  author: '作者',
  cover: '/books/images/book-id/cover.jpg',
  description: '简介',
  chapters: [
    { id: '1', title: '第1卷', cover: '/books/images/book-id/cover.jpg', status: '已完结', txtUrl: '/books/book-id/txt/书名 1.txt' }
  ]
}
```

## 七、自定义配置

### 7.1 网易云音乐播放器

编辑 `src/views Home.vue`，找到 iframe：

```html
<iframe src="//music.163.com/outchain/player?type=1&id=17982886763&auto=0&height=430" ...></iframe>
```

- `type=1`：歌单模式
- `id=17982886763`：歌单 ID（网易云 URL 中的数字）
- `auto=0`：不自动播放

### 7.2 快速链接 / 友情链接

编辑 `src/views/Home.vue`，修改对应的 `<a>` 标签。

### 7.3 网站 Logo

替换 `public/logo.png` 文件。

### 7.4 主题色

编辑 `src/assets/styles/main.css`：

```css
:root {
  --color-bg: #BDC0BA;         /* 页面背景色 */
  --color-accent: #9F353A;     /* 强调色 */
  --color-text: #333;          /* 文字颜色 */
  --color-text-secondary: #666; /* 次要文字颜色 */
}
```

## 八、部署与更新

### 8.1 本地构建与推送

```bash
npm run build
git add -A
git commit -m "更新说明"
git push origin main
```

### 8.2 Cloudflare Pages 部署

1. 登录 [Cloudflare Dashboard](https://dash.cloudflare.com/)
2. **Workers & Pages** → **Create application** → **Pages** → **Connect to Git**
3. 选择 GitHub 仓库
4. 构建配置：
   - **Build command**: `npm run build`
   - **Build output directory**: `dist`
5. 添加环境变量：

| 变量名 | 值 |
|--------|-----|
| `VITE_SUPABASE_URL` | Supabase 项目 URL |
| `VITE_SUPABASE_ANON_KEY` | Supabase ANON KEY |

6. 点击 **Save and Deploy**

### 8.3 初始化 Supabase 数据库

1. 打开 https://supabase.com → 进入项目
2. **SQL Editor** → 粘贴 `supabase-schema.sql` 内容 → **Run**

### 8.4 自定义域名

Cloudflare Pages 设置 → **Custom domains** → 添加域名。

### 8.5 环境变量

本地开发在 `.env` 文件中配置：

```
VITE_SUPABASE_URL=你的Supabase项目URL
VITE_SUPABASE_ANON_KEY=你的Supabase匿名密钥
```

## 九、Supabase 操作

### 9.1 数据表一览

| 表名 | 用途 | 匿名密钥权限 |
|------|------|-------------|
| posts | 博客文章 | 可读，写入需 RLS 策略 |
| comments | 文章评论 | 可读，写入需 RLS 策略 |
| likes | 文章点赞 | 可读，写入需 RLS 策略 |
| photos | 图片库图片 | 可读，写入需 RLS 策略 |
| announcements | 网站公告 | 只读，写入需后台操作 |

### 9.2 常用 SQL 查询

```sql
-- 查看所有文章
SELECT id, title, category, view_count, created_at 
FROM posts ORDER BY created_at DESC;

-- 查看评论数
SELECT p.title, COUNT(c.id) as comment_count
FROM posts p LEFT JOIN comments c ON c.post_id = p.id
GROUP BY p.id, p.title;

-- 查看点赞数
SELECT p.title, COUNT(l.id) as like_count
FROM posts p LEFT JOIN likes l ON l.post_id = p.id
GROUP BY p.id, p.title ORDER BY like_count DESC;

-- 查看浏览量最高的文章
SELECT title, view_count FROM posts ORDER BY view_count DESC LIMIT 10;

-- 通过 SQL 发布文章
INSERT INTO posts (title, summary, content, category, tags) VALUES (
  '文章标题',
  '文章摘要',
  '## 正文（Markdown格式）',
  'tech',
  ARRAY['标签1', '标签2']
);
```

## 十、常见问题

### Q: 图片加载慢？
A: 压缩图片（Python Pillow 或 tinypng.com），转换 WebP 格式，使用 CDN。

### Q: 如何修改网易云音乐歌单？
A: 修改 `src/views/Home.vue` 中 iframe 的 `id=17982886763` 为你的歌单 ID。

### Q: 如何添加新的友情链接？
A: 在 `src/views/Home.vue` 的友情链接区域添加新的 `<a>` 标签。

### Q: 公告不显示？
A: 检查 Supabase `announcements` 表是否有 `is_active=true` 的记录。

### Q: 部署后页面空白？
A: 检查浏览器控制台错误，通常是环境变量未正确设置。

### Q: 评论功能不工作？
A: 确认 Supabase 的 Realtime 功能已启用（Database → Replication）。
